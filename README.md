# Markup Challenge Homeworks

ეს რეპოზიტორია არის დავალებების წყარო. სტუდენტმა ეს პროექტი უნდა `clone`-ოს, წაიკითხოს შესაბამისი ინსტრუქცია და შემდეგ დავალება შეასრულოს უკვე საკუთარ GitHub რეპოზიტორიაში.

## როგორ უნდა იმუშაოს სტუდენტმა

1. დააკლონე ეს რეპოზიტორია:

```bash
git clone https://github.com/maribostashvili-93/homeworks-platform.git
```

2. GitHub-ზე შექმენი შენი საკუთარი რეპოზიტორია.
3. შენს რეპოზიტორიაში შექმენი შესაბამისი დავალების ფოლდერი.
4. დააკოპირე მხოლოდ საჭირო დავალების მასალები.
5. დავალება ატვირთე ფოლდერების სახით, არა `zip` ფაილად.

## ფოლდერების წესი

თითო დავალებისთვის შენს რეპოზიტორიაში უნდა არსებობდეს `2` ფოლდერი:

- `homework-X` - აქ უნდა იყოს სამუშაო ფაილები, მაგალითად `index.html`, `styles.css`, სურათები და სხვა რესურსები.
- `homework-X-solution` ან `assets` - მეორე ფოლდერი გამოიყენე იმ მასალებისთვის, რასაც კონკრეტული დავალება ითხოვს. თუ ინსტრუქციაში უკვე არის კონკრეტული სახელები, დაიცავი სწორედ ის სახელები.

თუ მენტორმა სხვა ფოლდერული სტრუქტურა მოგცა, უპირატესობა მიანიჭე მენტორის ინსტრუქციას.

## რა არ უნდა გააკეთოს სტუდენტმა

- არ იმუშაოს ამ წყაროს რეპოზიტორიაში პირდაპირ.
- არ ატვირთოს მთელი ეს რეპო თავის დავალების რეპოზიტორიაში.
